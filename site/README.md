# AIASSIST Project

This is a documentation and knowledge base project built with a custom UI design system.

## Features
- Interactive documentation with a sidebar navigation
- Searchable content with source attribution
- Composer section for user queries
- Responsive design with modern UI components

## Deployment

This project can be deployed to Supabase Pages. To do so:

1. Push this repository to GitHub
2. Connect your GitHub repository to Supabase Pages
3. Supabase will automatically build and deploy the site

For more information, see the [Supabase Pages documentation](https://supabase.com/docs/guides/pages).
