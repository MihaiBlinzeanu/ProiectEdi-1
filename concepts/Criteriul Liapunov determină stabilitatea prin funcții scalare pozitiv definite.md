Pentru un sistem autonom neliniar ẋ = f(x), metoda Liapunov presupune găsirea unei funcții V(x) cu proprietățile: (1) V(x) și derivatele parțiale sunt continue, (2) V(0) = 0, (3) V(x) > 0 pentru x ≠ 0 (pozitiv definită). Dacă derivata dV/dt în virtutea sistemului este negativ semidefinită sau identic nulă, sistemul este stabil. Dacă derivata este negativ definită, stabilitatea este asimptotică. Pentru sisteme liniare se alege V(x) = x₁² + x₂².
