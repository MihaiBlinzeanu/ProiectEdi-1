Ce este un BMS și ce rol are în clădirea inteligentă?

Un BMS (Building Management System) este sistemul centralizat de monitorizare, control și optimizare al clădirii.1 El leagă subsistemele individuale — climatizare, iluminat, securitate, acces — într-o singură platformă controlabilă.

Rolul lui în clădirea inteligentă este de integrare: clădirea devine „inteligentă" tocmai pentru că toate subsistemele sunt aduse într-un sistem unic, controlabil central, în locul unor insule separate.2 Arhitectura de comunicație tipică (de ex. KNX) este descentralizată, cu transmisie serială pe cablu BUS.3
